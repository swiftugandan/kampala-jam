# Kampala Jam

Drive the real streets of Kampala, from Speke Resort at Munyonyo to the Uganda Martyrs' Shrine at Namugongo, as fast as you can, without running over a boda boda.

You press DRIVE. The game decides what day it is. Finish and tomorrow is harder: Sunday Morning, An Ordinary Tuesday, Boxed In (Muyenga), Friday Evening, Rainy Season, Back to School, then busier and busier school terms. Your score is your time in seconds plus your penalty points.

The idea comes from an article by Dr Ian Clarke in New Vision, which imagined a computer game called "Kampala Traffic". This does not mean that Dr Clarke or New Vision endorse this game.

Play it at https://swiftugandan.github.io/kampala-jam/ or download it from [the latest release](https://github.com/swiftugandan/kampala-jam/releases/latest).

## Play it

| Device | How |
|---|---|
| Browser | https://swiftugandan.github.io/kampala-jam/play/ (if Chrome shows a blank green screen, try Firefox) |
| macOS | `kampala-jam-macos.zip` from the release |
| Windows | `kampala-jam-windows.zip` from the release |
| Linux | `kampala-jam-linux.zip` from the release |
| Android | `kampala-jam-android.apk` from the release |

Keyboard: arrows or WASD, Space to hoot, M for the map, Esc to pause. Gamepad: left stick points where to go, A hoots, B brakes. Touch: left thumb points where to go and how fast, right thumb brakes and hoots.

## Build from source

Needs Godot 4.7.2 and its export templates (`brew install --cask godot`), plus the Android SDK and JDK 17 for the APK.

```bash
godot --headless --path . --import                       # first time only
godot --path .                                           # run the game
godot --headless --path . -s res://tests/run_tests.gd    # tests
godot --headless --path . -s res://tests/run_tests.gd -- --soak   # a bot drives every day to the end (slow)
bash tools/export_all.sh                                 # builds all five platforms into build/
bash tools/package_release.sh                            # zips them into build/release/
bash tools/publish_site.sh                               # publishes site/ and the web build to gh-pages
```

## Rebuilding the data

```bash
python3 -I tools/osm/fetch.py          # download OpenStreetMap extracts (about 220 MB, gitignored)
python3 -I tools/osm/build_map.py      # writes assets/data/map_kampala.bin and map_meta.json
python3 -I tools/art/make_vehicles.py  # draws the vehicles as SVG
godot --headless --path . -s res://tools/art/bake_atlas.gd  # packs them into the atlas
python3 -I tools/audio/make_sfx.py     # synthesises the sound
```

`tools/osm/landmarks_curated.json` lists the landmarks that get a full sign. The build stops if one is not in OpenStreetMap, so nothing there is invented.

## Where things live

- `src/core/`: the simulation, with no rendering, which is why a bot can test it headless.
- `src/world/`, `src/ui/`: everything drawn on screen.
- `assets/data/game_rules.json`: penalties, days, hazards, car handling. `vehicle_catalog.json`: the fleet and motorcades. Tune here, not in code.
- `design/game-brief.md`: the design on one page.

Built on the [Claude Code Game Studios](https://github.com/Donchitos/Claude-Code-Game-Studios) template (MIT; its own README is at `docs/ccgs/README.md`). Run `claude` from this folder to get its agents and skills.
